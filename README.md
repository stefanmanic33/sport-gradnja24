# SPORT-GRADNJA Modern v2

Modernizovan statički responsive sajt za SPORT-GRADNJA Pirot.

## Kako se otvara

1. Raspakuj ZIP.
2. Otvori `index.html` u browseru.

## Struktura

- `index.html` - kompletan sadržaj sajta
- `css/styles.css` - dizajn i responsive stilovi
- `js/main.js` - izbor jezika i mobile meni
- `assets/` - slike koje su ubačene u galeriju i hero sekciju

## Jezici

U gornjem desnom uglu postoje prevodi za:
- srpski
- engleski
- nemački
- francuski
- bugarski

## Napomena

U kontakt sekciji sam ostavio placeholder za telefon: `+381 / unesite broj`. Kada dobiješ tačan broj, promeni ga u `index.html`.
